| 8 | 3 | `src/mem/dram_timing.cpp` (DRAM request legality) | First development run of the Phase 3 sweep: 26 of 115 configurations stopped with "illegal DRAM request (size not a multiple of bus width)", e.g. addr=49552 size=16 with W=32 | The Phase 1 rule (size a multiple of W, address W-aligned) was harmless while every test used W = 16.
